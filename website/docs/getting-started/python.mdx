# SDK de Python

El SDK oficial de Python es un cliente síncrono para Python 3.10 o posterior. Está disponible en [PyPI](https://pypi.org/project/facturapi/) y su código fuente se publica en [GitHub](https://github.com/facturapi/facturapi-python).

## Configuración

```bash
python -m pip install facturapi
```

```python
from facturapi import Facturapi

facturapi = Facturapi("sk_test_API_KEY")
```

También puedes guardar la llave en `FACTURAPI_KEY` y crear el cliente sin argumentos. Usa el cliente como context manager para cerrar sus conexiones automáticamente:

```python
from facturapi import Facturapi

with Facturapi(timeout=30) as facturapi:
    invoices = facturapi.invoices.list({"status": ["valid", "canceled"]})
```

Los métodos usan nombres en `snake_case`. Los cuerpos JSON se envían como diccionarios en `data`, los parámetros de URL como diccionarios en `params` y las respuestas JSON se devuelven como diccionarios o listas. Las descargas devuelven `bytes`.

```python
pdf = facturapi.invoices.download_pdf("invoice_id")
with open("factura.pdf", "wb") as file:
    file.write(pdf)
```

Para certificados, FIEL y logotipos, `files` acepta el mismo formato multipart de `httpx`:

```python
with open("certificate.cer", "rb") as cer, open("certificate.key", "rb") as key:
    facturapi.organizations.upload_certificate(
        "organization_id",
        {
            "cer": ("certificate.cer", cer),
            "key": ("certificate.key", key),
        },
        {"password": "certificate-password"},
    )
```

Las respuestas no exitosas lanzan `FacturapiResponseException`, que incluye `status_code`, `code`, `message`, `headers` y la respuesta JSON original.

```python
from facturapi.types.exc import FacturapiResponseException

try:
    facturapi.invoices.retrieve("invoice_id")
except FacturapiResponseException as error:
    print(error.status_code, error.code, error.message)
```

Este inventario corresponde al cliente generado desde el contrato OpenAPI público. Consulta la [referencia de la API](/api/) para conocer campos, filtros y respuestas de cada operación.
