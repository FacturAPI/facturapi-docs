Instalación del SDK

Contamos con librerías oficiales para los siguientes lenguajes:

Node.js
NPM
C#
NuGet
Java
Maven/Gradle
PHP
Composer

Si usas algún otro lenguaje, aún puedes consumir la API usando tu propio cliente HTTP.

Usando una de nuestras librerías oficiales​

Empieza por incluir el cliente de Facturapi en las dependencias de tu proyecto.

  • Node.js
  • C#
  • Java
  • PHP

Instala el paquete de NPM.

$> npm install --save facturapi

Instala el paquete de NuGet desde Visual Studio, o bien, desde la terminal del Package Manager:

dotnet add package Facturapi

Instala el paquete de Maven Central. Elige el bloque que corresponda con tu herramienta de construcción.

Usando Maven:

<dependency>
  <groupId>io.facturapi</groupId>
  <artifactId>facturapi-java</artifactId>
  <version>2.2.0</version>
</dependency>

Usando Gradle:

implementation("io.facturapi:facturapi-java:2.2.0")

Importa el paquete de Packagist usando composer:

$> composer require "facturapi/facturapi-php"

Importa la librería antes de usarla.

  • Node.js
  • C#
  • Java
  • PHP
  • cURL
const Facturapi = require('facturapi');

ESM / TypeScript

import Facturapi from 'facturapi';
using Facturapi;
import io.facturapi.Facturapi;
require_once __DIR__ . '/vendor/autoload.php';

use Facturapi\Facturapi;

Si tu framework ya carga el autoload de Composer automáticamente, puedes omitir require_once.

cURL no requiere de instalar un cliente adicional

Usando tu propio cliente HTTP​

Si consumes la API directamente usando tu propio cliente HTTP, no requieres instalar nada. Puedes avanzar a la siguiente sección.
